Vue d'ensemble de la matière

Ce cours est conçu pour guider les étudiants dans l'apprentissage des fondamentaux du développement web Front-End. Vous découvrirez comment structurer un document avec HTML5, le styliser avec CSS3 et lui donner de l'interactivité grâce à JavaScript.

Focus : Chapitre 4 - Positionnement CSS

Découvrez le fonctionnement de Flexbox et CSS Grid Layout pour concevoir des interfaces modernes et adaptatives.
